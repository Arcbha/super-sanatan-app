Connect your content repo

Plans and reference art are saved to the Content-distribution repo on GitHub. Paste a token once; it stays in this browser only.

Already set up on another device? Each phone or browser asks once. Make another token the same way (you can have several), or paste the one you saved.

  1. On github.com, open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → Content-distribution.
  3. Permissions → Repository → Contents: Read and write.
  4. Generate, copy the token (it starts with github_pat_) and paste it below.
