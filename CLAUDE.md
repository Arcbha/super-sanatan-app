# Super Sanatan — the phone/desktop front-end of the content planner

- Static page (GitHub Pages, this public repo): `index.html` + `app.js`, no build step, no secrets. It reads and writes **Arcbha/Content-distribution** (private) through the GitHub API with the editor's fine-grained token.
- **The data contract lives in Content-distribution**, not here: `planner/README.md`. Change a file format there first, then the page here, in the same session (attach both repos).
- Writes: `planner/plans.json` (read at the branch head and rewritten in the same commit, so devices don't overwrite each other) and files under `planner/refs/`. Also writes `planner/requests/<plan>-<time>.json` for **Write with Claude**; Content-distribution's `planner-ai-prompt.yml` Action answers into the plan's `aiPrompt`, and the app polls `plans.json` until it does. Bookmarks (`#bookmarks`) write `planner/bookmarks.json` + `planner/bookmarks/`; they are never sent to Claude. Artwork (`#artwork`) writes `planner/artworks.json` + `planner/artworks/`. Create (`#create`) writes `planner/creations.json` entries (with uploaded reference work under `planner/creations/<id>/refs/`) plus `planner/create-requests/<id>-<time>.json`; Content-distribution's `planner-create.yml` Action (Opus via Claude Code) writes a Midjourney prompt back (`mjPrompt`, `alternatives`, `why`; `mode: revise` uses `feedback`), and the app polls `creations.json` while one is active. Claude never makes images; they're made in Midjourney. Quotes (`#quotes`) write `planner/quotes.json` + `planner/quotes/`; never sent to Claude. Reads `planner/claude-accounts.json` (written by the Actions) for the Claude accounts card on Create: Account Google first, then Account Outlook. Reads: `data/panchang_2026.json`. The festival boost rules and weekday deities in `app.js` mirror `core/strategy_engine.py` there.
- UI: Rupee Mechanics-style SaaS, light only — soft grey radial ground, big rounded white cards (22 px) with layered shadows, a sticky pill tab bar (selected = dark ink pill), uppercase letter-spaced section labels, 48 px inputs. Inter only, no decorative fonts. One accent: the 6-stop soft gold → orange `--grad` (and `--grad-brand`, the brighter gold → orange for the word “Sanatan”, its first yellow toned down from #ffd84d to #f6c445), used sparingly (primary buttons, logo glow, today's card); text on it is `--on-grad` (dark brown, ≥ 4.7:1 at every stop).
- Test with Playwright against a mocked api.github.com (route interception) at 390 px and 1280 px wide before shipping; the editor uses it on a phone.
- Git: branch → PR → merge into `main` yourself (Pages serves `main`).
